# After the Pyramid

**ECON1626 Assessment 3: AI Future Forecast**

This repository contains an interactive web essay forecasting how AI agents may reshape Australia's consulting industry by 2030.

## Project thesis

AI agents are unlikely to eliminate consultants, but they may eliminate the traditional consulting pyramid by automating many research, analysis, documentation, and coordination tasks. The economic outcome depends on who captures the resulting productivity gains.

## Files

- `forecast.html` — the complete essay and page structure
- `styles.css` — responsive visual design
- `script.js` — interactive scenarios, pyramid comparison, gains simulation, and reading progress
- `Thesis.docx` — original working draft

## Interactive elements

- A 2030 AI-assisted consulting project timeline
- A 2025 versus 2030 consulting pyramid comparison
- A "Who Captures the Gains?" distribution simulation
- Baseline, upside, and downside scenario toggles
- Policy playbook with risks, mitigations, and KPIs

## Run locally

Open `forecast.html` in a browser. No build process or external JavaScript libraries are required.

## GitHub Pages

1. Upload or push all project files to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the main branch and the root folder.
5. Save the setting and open the published URL.

## Reproducibility

The website uses plain HTML, CSS, and JavaScript so that it can render directly on GitHub Pages. The interactive gains model is illustrative rather than an empirical estimate. Its assumptions are described in the Methods section of the essay.
